# Safe Federation for Reads

<v-clicks>

## What We Need

1. **Advisory feeds** following changes contract
2. Rapid upstream notifications
3. Lightweight, cacheable responses
4. Prevent serving known malware

## The Key Insight

> You do **NOT** need to bring in the actual content

- NPM: tarballs
- Java: JARs
- Python: wheels

Can all be offloaded with **Sigstore** + attestations
