# The Tombstone Problem at Scale

<v-clicks>

## What Happened

- Tombstones from large packages became **sizable**
- Had to seek over them for more changes
- Attachments separated ~10 years ago
- Worked for a time...

## GitHub's Migration (Feb 2025)

```diff
- GET /npm/_changes?include_docs=true
+ GET /npm/_changes?include_docs=false
```

Now you only get **document ID + revision**
