# Putument vs Packument

<v-clicks>

## The Packument
- The full package document
- What you see in the registry
- Contains all versions

## The Putument
- **P**artial p**U**blish doc**UMENT**
- Used during publishing
- Makes atomicity possible
- A unique & distinct entity

</v-clicks>
