# Lexicographic Pivots

```javascript
// Pivots create partition boundaries
const pivots = [
  '@', '@angular', '@babel', '@types',
  'a', 'babel', 'express', 'react',
  'webpack', 'z'
]

// Becomes partition pairs
const partitions = [
  { start: '@', end: '@angular' },
  { start: '@angular', end: '@babel' },
  { start: '@babel', end: '@types' },
  // ... ~1,200 partitions total
]
```
